# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-10-04

### Added
- Initial release of Erasmus33 platform
- User authentication with Supabase (sign up, login, password reset)
- House browsing and detailed view with image galleries
- Room browsing and detailed view
- Search and filter functionality for houses and rooms
- Pagination controls for browsing listings
- Admin dashboard for managing houses, rooms, and users
- Admin image manager for property photos
- User profile management
- Responsive design with dark mode support
- Landing page with hero section showcasing Guarda, Portugal
- Protected routes with authentication middleware

### Tech Stack
- Next.js 15 with App Router and Turbopack
- TypeScript for type safety
- Supabase for backend and authentication
- Tailwind CSS for styling
- shadcn/ui for UI components
- React 19 for the frontend

### Documentation
- Comprehensive README with setup instructions
- Contributing guidelines
- Environment variable documentation
- Project structure documentation

## How to Update This Changelog

When making changes, add them under the "Unreleased" section at the top:

## [Unreleased]

### Added
- New features

### Changed
- Changes in existing functionality

### Deprecated
- Soon-to-be removed features

### Removed
- Removed features

### Fixed
- Bug fixes

### Security
- Security improvements

Then, when releasing a new version, move the changes to a new version section with the date.
